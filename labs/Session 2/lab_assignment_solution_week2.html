Mutating and pivoting

library(nycflights13)
flights <- flights

“Flights” is a larger dataset that contains data on flights leaving from New York airports in 2013. We are performing some calculations on flight times and delays to practice creating variables and doing more complex summary operations.

  1. distance contains the distance of a flight in miles. air_time contains the time a flight spent in the air, in minutes. Create two columns called “km” and “hours” that contain the distance in kilometres and the time in hours (a mile is 1.609 km).
flightdata <- flights |> 
  mutate(km = distance*1.069,
         hours = air_time/60)
  1. Create a column showing the average speed of each flight.
flightdata <- flightdata |> 
  mutate(avg_speed = km/hours)

  1. Using mutate(case_when()), tag flights based on which season they occurred in (Winter for December-February, Spring for March-May, Summer for June-August, Autumn for September-November).
flightdata <- flightdata |> 
  mutate(season = case_when(
    month <= 2 | month == 12 ~ "Winter",
    month >= 3 & month <= 5 ~ "Spring",
    month >= 6 & month <= 8 ~ "Summer",
    month >= 9 & month <= 11 ~ "Autumn"
  ))
  1. Which season has the longest average delay? (Use ?flights to find out which column contains which data).
delays <- flightdata |>
