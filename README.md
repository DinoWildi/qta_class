# Welcome to the seminar "Introduction to Quantitative Text Analysis"!

Quantitative text analysis (QTA), the automated analysis of text, has become a very popular method in political science research over the past years. Political actors produce large amounts of texts that are accessible via the internet (e.g. manifestos, press releases, speeches, social media posts, etc.), making methods that can analyse these texts at a large scale an increasingly important tool for researching political behaviour. At the same time, new technologies such as large language models (LLMs) allow for increasingly sophisticated and powerful QTA methods.

This seminar will introduce students to the basic assumptions and logics behind QTA in four steps. First, you will learn the basic logic and assumptions behind QTA, and be introduced to building blocks and concepts such as documents, tokens, features, and document-feature-matrices. Second, you will build a toolbox of traditional QTA methods using the specialised R package quanteda and practice those techniques with pre-defined texts. Third, you will learn how to identify, access, and prepare texts for your own research questions. Finally, we will take a brief look at cutting-edge techniques based on LLMs.

### How to use the repository
If you are a GitHub user, you can clone the repository and use it directly via GitHub. This makes coding tasks easier and is good practice for future projects. If you are not interested in using GitHub, you can also download a file from the repository by clicking onto the file name, then clicking on the three dot menu in the upper right corner, and clicking "Download". I highly recommend using GitHub and can offer assistance with downloading GitHub Desktop, setting it up, and cloning the repository.
Please avoid pushing anything to this repository yourself (although feel free to do so with your cloned version).
